## Project Overview

This project analyzes employee attrition using Power BI. It helps identify patterns in employee turnover based on department, salary, and age groups.

## Key Features

* Total Employees, Attrition Count, Attrition Rate
* Attrition by Department and Job Role
* Salary group analysis (Low, Medium, High)
* Age group analysis (18–24, 25–34, etc.)
* Interactive slicers

## Key Insights

* Research & Development has the highest attrition
* Employees with low salary (<3000) leave the most
* Age group 25–34 shows highest attrition

## Tools Used

* Power BI
* DAX (calculated columns & measures)
